# 删除实例说明

本文档说明「删除实例」的接口、数据流、多场景引用保护、子节点处理方式，以及与删除场景的对比。

---

## 一、流程概览

1. 前端调用 **DELETE /instances/{instance_id}**，传入实例 uid。
2. 后端根据 `instance_id` 查实例，不存在则 404。
3. **检查是否被多个场景引用**：如果 `len(inst.scenes) > 1`，返回 400，不允许删除。
4. **删除 MongoDB 的 property**：如果 `inst.properties` 有 `_id`，删除对应的 `instance_properties` 文档。
5. **删除 Neo4j 节点**：`inst.delete()` 删除节点及其所有关系。
6. 返回成功消息。

**注意**：删除实例**不会递归删除子节点**，子节点会保留，但父关系会被删除（可能变成"孤儿"）。

---

## 三、路由内逻辑（逐行）

```python
# 1. 根据 instance_id 查实例，不存在则 404
inst = Instance.nodes.get_or_none(uid=instance_id)
if not inst:
    raise HTTPException(404, "实例不存在")

# 2. 检查是否被多个场景引用
if len(inst.scenes) > 1:
    raise HTTPException(400, "该实例被多个场景引用，不能直接删除")

# 3. 删除绑定的 property（Mongo）
if inst.properties and "_id" in inst.properties:
    await db.instance_properties.delete_one({"_id": ObjectId(inst.properties["_id"])})

# 4. 删除 Neo4j 节点（会自动删除所有关系）
inst.delete()

# 5. 返回成功消息
return {"message": "实例已删除"}
```

## 四、关键点说明

### 1. 多场景引用保护

**原因**：一个实例可能被多个场景共享（通过 HAS_INSTANCE 关系）。

**规则**：如果实例被多个场景引用（`len(inst.scenes) > 1`），不允许通过删除实例接口删除。

**实现**：
```python
if len(inst.scenes) > 1:
    raise HTTPException(400, "该实例被多个场景引用，不能直接删除")
```

**场景示例**：
- 场景 A 和场景 B 都引用了同一个实例（共享资产）
- 删除实例时，如果只删除一个场景的引用，另一个场景的引用会失效
- 因此，被多个场景引用时，不允许直接删除

---

### 2. 子节点不会递归删除

**neomodel 的 delete() 行为**：
- ✅ 删除节点本身
- ✅ 删除该节点的所有关系（PARENT_OF、HAS_INSTANCE 等）
- ❌ **不递归删除子节点**

**影响**：
- 删除实例时，子节点会保留
- 但 `(父)-[:PARENT_OF]->(子)` 关系会被删除
- 子节点可能变成"孤儿"（没有父节点，但仍存在）

**示例**：
```
删除前：
根实例
  └─ 实例A (要删除)
      ├─ 子实例B (保留)
      └─ 子实例C (保留)

删除后：
根实例
子实例B (孤儿，没有父节点)
子实例C (孤儿，没有父节点)
```

---

### 3. MongoDB property 的清理

**原因**：如果 `inst.properties` 有 `_id`，说明引用了 MongoDB 的 `instance_properties` 文档。

**实现**：
```python
if inst.properties and "_id" in inst.properties:
    await db.instance_properties.delete_one({"_id": ObjectId(inst.properties["_id"])})
```

**目的**：避免数据残留，删除实例时同时删除对应的 property 文档。

---

### 4. neomodel 的 delete() 行为

**删除的内容**：
- Instance 节点本身
- 该节点的所有关系：
  - `(父)-[:PARENT_OF]->(当前实例)` 关系
  - `(当前实例)-[:PARENT_OF]->(子)` 关系（但子节点不删除）
  - `(场景)-[:HAS_INSTANCE]->(当前实例)` 关系

**不删除的内容**：
- 子节点（会保留，但父关系被删除）

## 五、与删除场景的对比

### 删除场景（scene.py 149-172）

```python
@router.delete("/scenes/{scene_id}", response_model=dict)
async def delete_scene(scene_id: str, current_user: UserInDB = Depends(get_current_active_user)):
    scene = Scene.nodes.get_or_none(uid=scene_id)
    if not scene:
        raise HTTPException(404, "场景不存在")
    # 检查所有instance是否被其他场景引用
    root = scene.root.single()
    if root:
        to_delete = []
        def collect_instances(inst):
            # 检查是否被其他场景引用
            if len(inst.scenes) <= 1:
                to_delete.append(inst)
            for child in inst.children:
                collect_instances(child)
        collect_instances(root)
        # 删除instance及其property
        for inst in to_delete:
            # 删除绑定的property（Mongo）
            if inst.properties and "_id" in inst.properties:
                await db.instance_properties.delete_one({"_id": ObjectId(inst.properties["_id"])})
            inst.delete()
    scene.delete()
    return {"message": "场景及未被引用的实例已删除"}
```

### 对比表

| 项目 | 删除场景 | 删除实例 |
|------|----------|----------|
| 递归删除 | ✅ 是（collect_instances 递归收集） | ❌ 否（只删除当前节点） |
| 子节点处理 | ✅ 递归删除所有子节点 | ❌ 子节点保留，但父关系被删除 |
| 多场景引用检查 | ✅ 检查每个实例是否被其他场景引用 | ✅ 检查当前实例是否被多个场景引用 |
| 删除范围 | 场景 + 所有未被其他场景引用的实例 | 只删除当前实例 |
| 删除顺序 | 先删除实例，再删除场景 | 只删除当前实例 |

## 七、潜在问题与注意事项

### 1. 子节点变成"孤儿"

**问题**：
- 删除实例时，子节点不会自动删除
- 子节点会保留，但父关系被删除
- 可能导致数据不一致

**建议**：
- 删除实例前，先手动删除或移动子节点
- 或者修改代码，添加递归删除子节点的逻辑

---

### 2. 多场景引用保护

**问题**：
- 被多个场景引用时，不能直接删除
- 需要先解除其他场景的引用，或使用其他方式处理

**建议**：
- 删除实例前，先检查是否被多个场景引用
- 如果被多个场景引用，先解除其他场景的引用，再删除

---

### 3. 删除顺序

**当前实现**：
1. 先删除 MongoDB 的 property
2. 再删除 Neo4j 的节点

**潜在问题**：
- 如果 MongoDB 删除失败，Neo4j 节点仍会被删除（可能造成数据不一致）

**建议**：
- 使用事务保证原子性
- 或者先删除 Neo4j 节点，再删除 MongoDB 文档（如果 Neo4j 删除失败，MongoDB 文档仍保留）

## 九、小结

- **删除实例**：DELETE /instances/{instance_id}，无请求体，删除当前实例节点及其所有关系。
- **多场景引用保护**：如果实例被多个场景引用（`len(inst.scenes) > 1`），不允许直接删除，返回 400。
- **子节点不会递归删除**：删除实例时，子节点会保留，但父关系被删除（可能变成"孤儿"）。
- **MongoDB property 清理**：如果 `inst.properties` 有 `_id`，删除对应的 `instance_properties` 文档。
- **neomodel 的 delete()**：删除节点及其所有关系，但不递归删除子节点。
- **与删除场景的区别**：删除场景会递归删除所有未被其他场景引用的实例，删除实例只删除当前节点。
